# seltudy.github.io

셀터디(Seltudy) 조직의 GitHub Pages 맨 위 주소(`https://seltudy.github.io/`)에 두는 파일이다. 빌드 없이 그대로 올린다(`.nojekyll`).

## app-ads.txt

- AdMob은 App Store에 적은 앱의 마케팅 URL 도메인 맨 위에서 `app-ads.txt`를 찾는다. 캐치노티의 마케팅 URL은 이 도메인(`seltudy.github.io`) 아래에 둔다.
- 줄은 앱이 아니라 AdMob 계정(게시자 ID `pub-9407043455491646`)을 가리킨다. 마케팅 URL이 이 도메인인 앱은 모두 이 파일 하나를 함께 쓴다.
- 다른 광고 네트워크를 붙이면 그 회사가 주는 줄을 아래에 더한다.
- AdMob 콘솔(앱 › 모든 앱 보기 › app-ads.txt)에 나오는 줄과 같아야 한다.
